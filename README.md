Project Overview

This project is a website and e-commerce platform for a coffee exporting company. The application was developed using React.js for the frontend and Node.js with Express.js for the backend.

The backend architecture follows a structured and normalized database design using Sequelize ORM and MySQL as the database management system. The system provides efficient data management, scalability, and maintainability through well-designed relational database schemas.

The platform includes secure online payment processing integrated with CyberSource through the Bank of Abyssinia (BOA) payment gateway, enabling customers to complete transactions safely and efficiently.

Technology Stack
Frontend: React.js
Backend: Node.js, Express.js
ORM: Sequelize
Database: MySQL
Payment Gateway: CyberSource (via Bank of Abyssinia - BOA)
Features
Coffee product catalog management
E-commerce shopping functionality
Secure online payment integration
Customer and order management
Responsive user interface
Scalable and normalized database architecture
